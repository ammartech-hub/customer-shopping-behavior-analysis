 # 📊 Customer Shopping Behavior Analysis

An end-to-end data analytics project analyzing **3,900 customer shopping transactions** using Python, PostgreSQL, SQL, and Power BI.

## 📌 Project Overview

This project focuses on understanding customer purchasing patterns, product performance, discounts, subscriptions, customer segments, and revenue trends.

## 🛠️ Tools & Technologies

- Python
- Pandas & NumPy
- Matplotlib
- Jupyter Notebook
- PostgreSQL
- SQL
- Power BI
- Gamma

## 🔄 Project Workflow

**Data Loading → EDA → Data Cleaning → Feature Engineering → PostgreSQL → SQL Analysis → Power BI Dashboard → Business Insights**

## 🐍 Python Analysis

- Loaded and explored the dataset
- Performed Exploratory Data Analysis (EDA)
- Handled missing values
- Cleaned and transformed the data
- Created features such as age groups and purchase frequency

## 🐘 SQL Analysis

The project answers key business questions including:

- Revenue by gender
- High-spending customers using discounts
- Top 5 products by review rating
- Standard vs. Express shipping
- Subscribers vs. non-subscribers
- Discount usage by product
- Customer segmentation
- Top 3 products within each category
- Repeat buyers and subscription behavior
- Revenue by age group

## 📊 Power BI Dashboard

An interactive dashboard was created to visualize:

- Customer count
- Average purchase amount
- Average review rating
- Revenue by category
- Product performance
- Subscription status
- Payment methods
- Customer demographics
